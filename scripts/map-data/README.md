# Southern Vietnam route map

Country geometry is a subset of Natural Earth's public-domain 1:50m Admin 0 countries dataset:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson

Retrieved November 24, 2026. Includes Vietnam, Cambodia, Laos and Thailand.

`python scripts/build-southern-route-map.py` regenerates the SVG and shareable PNG from this geometry and the curated itinerary labels. Road and flight connections are illustrative, not navigation or flight tracks. The Mekong Delta marker represents the excursion region rather than an overnight stop.
